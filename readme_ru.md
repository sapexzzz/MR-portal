# Mentalitys | MR Portal

Mentalitys | MR Portal — мод для Fabric 1.20.1, который добавляет персональные порталы и точки телепортации в стиле Magic Rampage.

Текущая версия: 2.3

## Что делает мод

MR Portal позволяет каждому игроку сохранять свои точки и открывать временные порталы к ним. Исходный портал появляется перед игроком, а после телепортации появляется портал назначения. Пока портал активен, через него могут проходить другие игроки и сущности.

Базовый мод поддерживает обычное выживание, одноразовые свитки, креативный/админский посох, избранную точку и быстрый бинд для избранного портала.

## Возможности

- Мод для Fabric 1.20.1.
- Персональные точки для каждого игрока.
- GUI для добавления, выбора, переименования, удаления и отметки избранной точки.
- Посох портала для выживания.
- Бесконечный посох портала для креатива и админского использования.
- Свиток телепорта как одноразовый предмет.
- Избранная точка.
- Быстрый бинд для портала к избранной точке.
- Предпросмотр / точка предпросмотра при выборе назначения.
- Портал открывается перед игроком.
- После телепортации появляется портал назначения.
- Через активные порталы могут проходить другие сущности и игроки.
- Обычный посох и свиток работают только в текущем измерении.
- Бесконечный посох и креатив могут обходить обычные ограничения по измерениям.
- Настраиваемые тайминги, стоимость, размер портала, язык и визуальное поведение.

## Новое в 2.3

Версия 2.3 обновляет внутренний слой телепортации, не меняя стандартный игровой процесс MR Portal:

- Телепорт из GUI теперь проходит через сервис запросов.
- Быстрый портал к избранной точке тоже проходит через сервисный слой.
- Аддоны могут регистрировать свои обработчики телепортации через публичный API.
- Активный обработчик выбирается по приоритету.
- Базовый MR Portal оставляет за собой проверки, оплату, кулдаун, расход предметов и ограничения по измерениям.
- Обработчики отвечают за стиль выполнения и поведение телепорта после базовой проверки.
- Обработчик может управлять стандартной точкой предпросмотра через `usesDefaultPreviewSpark()`.
- Встроенный обработчик сохраняет обычное поведение порталов MR Portal.

Это подготавливает MR Portal к внешним аддонам, например к отдельной поддержке Chrono Portal, без жёсткой привязки логики аддона к базовому моду. Chrono Portal не встроен в базовый MR Portal.

## Предметы

### Посох портала

- ID: `mr_portal:portal_staff`
- Предмет для выживания.
- Тратит эндер-жемчуг, когда портал начинает открываться.
- Накладывает кулдаун на посох.
- Работает только в текущем измерении.

### Свиток телепорта

- ID: `mr_portal:teleport_scroll`
- Одноразовый предмет для телепортации.
- Расходуется, когда портал начинает открываться.
- Не требует эндер-жемчуг.
- Не накладывает кулдаун посоха.
- Работает только в текущем измерении.

### Бесконечный посох портала

- ID: `mr_portal:infinite_portal_staff`
- Предмет для креатива и админского использования.
- Не тратит эндер-жемчуг.
- Не имеет кулдауна.
- Может обходить обычные ограничения по измерениям.

## Как использовать

1. Возьмите посох портала или свиток телепорта.
2. Нажмите ПКМ, чтобы открыть GUI точек.
3. Добавьте текущую позицию как точку или выберите уже существующую.
4. Подтвердите телепорт, чтобы создать портал перед игроком.
5. Зайдите в портал, чтобы телепортироваться.

Также можно использовать настроенный бинд быстрого открытия GUI, если в инвентаре есть посох или свиток.

Оплата происходит в момент запуска портала, а не при простом открытии GUI.

## Избранная точка и быстрый портал

- В GUI можно отметить одну точку как избранную.
- Быстрый бинд создаёт портал к избранной точке.
- Перед активацией быстрого портала показывается предпросмотр с задержкой.
- Оплата происходит при отложенной активации, а не при нажатии клавиши.
- Приоритет предметов для быстрого портала: бесконечный посох, обычный посох, свиток телепорта.
- Быстрый портал с обычным посохом или свитком работает только в текущем измерении.
- Бесконечный посох и креатив могут обходить обычные ограничения.

## Поддержка аддонов и API

MR Portal 2.3 содержит API обработчиков телепортации для внешних аддонов.

Аддон-обработчик может:

- зарегистрировать `MRPortalTeleportHandler`;
- стать активным обработчиком по приоритету;
- принять или отклонить уже проверенный запрос;
- выполнить другой стиль телепорта после базовой проверки;
- отключить стандартную точку предпросмотра через `usesDefaultPreviewSpark()`.

Базовый MR Portal всё ещё отвечает за:

- владение точками и их поиск;
- определение предмета телепорта;
- проверку измерения;
- проверку и списание эндер-жемчуга;
- расход свитка;
- проверку и применение кулдауна посоха;
- тайминг GUI и быстрого избранного портала.

Так аддоны могут менять визуальный стиль или способ телепортации, не ломая базовую экономику и правила мода.

## Конфиг

Файл создаётся автоматически:

- `config/mr_portal.json`

Параметры:

- `language`: язык мода, `auto`, `en` или `ru`.
- `cooldownSeconds`: кулдаун обычного посоха в секундах.
- `maxWaypoints`: лимит точек на игрока.
- `portalOpenDelay`: время открытия портала в тиках.
- `portalActiveTicks`: сколько портал остаётся открытым после раскрытия.
- `portalCloseDelayTicks`: сколько портал остаётся после телепорта перед началом закрытия.
- `portalPearlCost`: стоимость телепорта обычным посохом.
- `applyBlindnessOnTeleport`: включает или отключает слепоту после телепорта.
- `blindnessDuration`: длительность слепоты в тиках.
- `portalScale`: визуальный размер портала.
- `portalSpawnDistance`: расстояние от игрока до исходного портала.
- `portalVerticalOffset`: вертикальное смещение портала.
- `portalAnimationSpeed`: множитель скорости анимации портала.
- `quickFavoritePortalDelayTicks`: задержка перед запуском быстрого избранного портала.
- `portalExitBehindDistance`: насколько далеко за игроком появляется портал назначения после телепорта.

Значения по умолчанию:

- `language = auto`
- `cooldownSeconds = 60`
- `maxWaypoints = 10`
- `portalOpenDelay = 60`
- `portalActiveTicks = 100`
- `portalCloseDelayTicks = 60`
- `portalPearlCost = 3`
- `applyBlindnessOnTeleport = true`
- `blindnessDuration = 40`
- `portalScale = 1.5`
- `portalSpawnDistance = 2.2`
- `portalVerticalOffset = 0.0`
- `portalAnimationSpeed = 1.0`
- `quickFavoritePortalDelayTicks = 30`
- `portalExitBehindDistance = 0.2`

Настройки можно менять в игре через ModMenu -> Mentalitys | MR Portal, если установлен Cloth Config API.

## Зависимости

- Fabric API для Minecraft 1.20.1.
- Cloth Config API рекомендуется для экрана настроек в игре.
- ModMenu рекомендуется для открытия настроек через меню модов.

Цель проекта: Java 17.

```bash

```

Готовый jar появляется в `build/libs`.

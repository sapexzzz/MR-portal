# MR Portal 2.3 — список изменений

MR-Portal 2.3 — в первую очередь внутреннее обновление API и сервисного слоя. Оно подготавливает базовый мод к внешним аддонам со своими стилями телепортации, при этом обычное поведение MR-Portal сохраняется.

## Основные изменения

- Добавлен публичный API обработчиков телепортации.
- Добавлен `MRPortalApi`.
- Добавлен `MRPortalTeleportHandler`.
- Добавлен `MRPortalTeleportContext`.
- Добавлен `MRPortalWaypointView`.
- Добавлен `MRPortalTeleportActivator`.
- Добавлена регистрация обработчиков и выбор активного обработчика по приоритету.
- Добавлен встроенный обработчик по умолчанию для обычного поведения порталов MR-Portal.
- Запросы телепорта из GUI к точкам теперь проходят через новый сервисный/API-путь.
- Быстрый телепорт к избранной точке теперь проходит через новый сервисный/API-путь.
- Проверки оплаты, кулдауна и ресурсов остаются в базовом моде.
- Сохранены стоимость эндер-жемчугом и кулдаун для обычного посоха портала.
- Сохранено расходование предмета для свитка телепорта.
- Сохранено поведение бесконечного посоха портала без оплаты.
- Сохранены ограничения одного измерения для обычного посоха портала и свитка телепорта.
- Добавлен управляемый обработчиком hook стандартной точки предпросмотра / preview spark через `usesDefaultPreviewSpark()`.
- Обработчик по умолчанию сохраняет обычное поведение preview spark.
- Обработчики внешних аддонов могут отключать базовую визуальную точку предпросмотра.

## Исправления и проверка

- Исправлен путь расходования свитка телепорта из GUI: режим GUI для свитка/посоха теперь определяется сервером.
- Исправлена регрессия оплаты обычным посохом портала при быстром телепорте к избранной точке, если в инвентаре также был свиток.
- Вручную проверено поведение посоха портала и свитка телепорта через GUI.
- Вручную проверено поведение посоха портала и свитка телепорта через быстрый телепорт к избранной точке.
- Вручную проверено открытие и очистка точки предпросмотра / preview spark.
- Удалены временные диагностические логи `[MRP07F]`.

## Поддержка аддонов

- Это обновление не включает Chrono Portal в базовый мод.
- Оно подготавливает MR-Portal к отдельным внешним аддонам, например Chrono Portal.
- MR-Portal не содержит жёстко прописанной логики Chrono.
- Chrono должен быть отдельным jar-файлом, установленным рядом с MR-Portal.

## Заметки для разработчиков

- Базовый мод отвечает за проверки, оплату, кулдаун и ресурсы.
- Обработчики отвечают за стиль выполнения телепорта после проверок.
- `usesDefaultPreviewSpark()` управляет только стандартной визуальной точкой предпросмотра, а не оплатой или выполнением сессии.
- Встроенный обработчик по умолчанию внутри себя остаётся без оплаты; оплата выполняется до запуска обработчика.

## Известные заметки

- Исчезновение кулдауна посоха портала после повторного входа остаётся старым поведением vanilla cooldown.
- Runtime-проверка обработчиков внешних аддонов — будущая работа.
- Реализация Chrono остаётся отдельной/будущей задачей.

## Зависимости и сборка

- Fabric 1.20.1.
- Цель проекта: Java 17.
- В этом рабочем окружении Gradle запускается через Java 21.
- Сборка проверена командами:

```bash
JAVA_HOME=/usr/lib/jvm/java-21-openjdk ./gradlew compileJava
JAVA_HOME=/usr/lib/jvm/java-21-openjdk ./gradlew compileClientJava
```

# MR-Portal Base Notes Board

This board tracks base MR-Portal work only.

Use this Notes folder for:

- API work implemented inside the original/base MR-Portal mod.
- Audits of MR-Portal source code.
- Reports for modifying MR-Portal itself.
- The base MR-Portal canvas and phase notes.

Base MR-Portal reports and audits live under:
`MR-portal/Notes/REPORTS&AUDITS/`

Base MR-Portal Obsidian board files live under:
`MR-portal/Notes/OBSIDIAN_BOARD/`

Base API work happens here because the public API will live inside `mr-portal.jar`.

Chrono addon docs do not live in this folder. From the `MR-portal/` root, Chrono notes are at:
`../Add-ons/Chrono/Notes/`

Do not store addon design, addon architecture, or addon report files in `MR-portal/Notes/`.

Root-level `Notes/` is not used for active project tracking.
